Simulateur de progression

Où démarre chaque exercice selon la note d'athlète, et ce qu'il demande séance après séance à quelqu'un qui réussit toujours, sans rien répondre : chaque séance le fait monter d'un palier. On cherche un palier qui demande moins de volume que le précédent (en orange), et on le corrige à la main dans le tableau des paliers. Le fichier à coller est en bas de page.

Le parcours, séance après séance

Les ronds pleins marquent un changement de mouvement, les cercles orange une baisse de volume. Touche un point pour retrouver son palier dans le tableau.

Les paliers

Chaque ligne est un palier, tel que le matériel le joue. Une case orange demande moins de volume que le palier du dessus. Les deux champs corrigent les séries et la cible de ce palier pour tous les matériels (le poids reste celui que le matériel permet) ; vide, le palier reprend sa valeur calculée.

Le tableau montre tous les paliers ; le parcours, ceux qu'on vit vraiment. Une case orange que le parcours ne signale pas est un palier sauté : réussir une performance qui vaut un palier plus haut y fait passer directement (corriger le palier 1 à 3×8 fait sauter jusqu'au palier qui demandait déjà 3×8).
